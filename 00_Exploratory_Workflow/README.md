# Exploratory Workflow

This directory documents the exploratory phase of the research project.

The purpose of this phase was to determine whether the planned
forensic bioinformatics workflow could be made operational under
resource and technical constraints.

During this phase, the Linux computing environment, remote access,
software dependencies, STRait Razor, and initial NGS data workflows
were configured and tested.

AI assistance was used extensively for technical troubleshooting,
command-line interpretation, software configuration, and workflow
development.

These records are retained as development provenance and are not
treated as final experimental results.
